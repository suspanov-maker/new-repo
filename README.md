# Семейный помощник по турам

Агент для Claude Code, который ищет и сравнивает варианты семейного отдыха.

## Как пользоваться

1. Заполните `family-profile.md`.
2. Откройте этот репозиторий в Claude Code.
3. Напишите, например: «используй family-travel и подбери отдых на майские».

Агент описан в `.claude/agents/family-travel.md`. Его правила можно менять обычным текстом.
